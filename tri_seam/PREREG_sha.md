# Independent re-measurement of |Sha(E/Q)[ψ]|: preregistration

Written and committed **before** the harness was written or run. 2026-10-24.

## What is measured

For each companion curve, with D = abc over the 393 admissible cubics (315 distinct D):

    |Sha(E/Q)[ψ]| = |Sel^ψ(E/Q)| / |E′(Q)/ψE(Q)|          (the record's exact sequence, section 1)

Here E: x³ + y³ = Dz³ and E′: η² = ξ³ + 16D².

## Method (fixed in advance; no PARI)

1. **Sel^ψ.**
   - Candidate classes are q = ∏ p^{e_p} over the primes p | 3D, with e_p ∈ {0, 1, 2}. Selmer classes are unramified outside 3D; for p ∤ 3D the cubic is smooth mod p.
   - The covering for class q is C_q: cf(D q²) x³ + cf(q) y³ + z³ = 0, where cf is the cube-free part. This comes from the record's normalisation m = [b/c] with abc ≡ D: the triple (Dq²c, qc, c) is a multiple of (Dq², q, 1).
   - q ∈ Sel^ψ iff C_q is locally solvable at every p | 3D. The test is the exact Hensel test `solvable_at` in `cubic_faces.py`, already validated (R1, R4). The real place is automatic for cubics.
2. **im δ = E′(Q)/ψE(Q).**
   - For the 308 curves mwrank decided: the subgroup generated by [D] and δ of the saturated generators (`descent_results.json`). Membership uses the exact cube test in `descent_check.py`.
   - For the 7 curves certified analytically (`lfun_results.json`): rank 0, so im δ = ⟨[D]⟩.
3. **Sha size:** |Sha[ψ]| = |Sel| / |im δ|.

## Predictions

- **S0 (consistency; a failure here means the method is wrong, not the record).** For every curve:
  - im δ ⊆ Sel^ψ;
  - |Sel| / |im δ| is a power of 3;
  - q = 1 and q = [D] lie in Sel^ψ.

  For every cubic:
  - each of the 157 obstructed cubics has m ∈ Sel^ψ \ im δ;
  - each of the 236 solvable cubics has m ∈ im δ.
- **S1.** The distribution over the 315 curves is |Sha[ψ]| = 1 for **196**, 9 for **117** and 81 for **2**. The two of size 81 are **D = 5610 and D = 20010**.
- **S2.** Per-curve agreement with the record's `seam_sha_results.json` on all 315 curves, if that file's format can be read automatically. If it can't, this is reported as untested.
- **S3.** Every D carrying an obstructed cubic has |Sha[ψ]| ≥ 9.
- **S4 (re-observation only).** All 315 sizes are squares (dim_F₃ Sha[ψ] is even). *Why* stays **OPEN**: this run does not compute the dual group Sha(E′)[ψ̂] or Cassels' Selmer ratio.

## Limits stated in advance

- The local test and cube arithmetic are this project's own code. The generators come from mwrank. The 7 rank-0 facts are NUMERICAL + THEOREM, from the analytic check.
- This measures Sha[ψ] only, not Sha[3] or the full Sha.
